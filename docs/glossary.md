# Glossary: Bangla and English terms

One word per idea everywhere: storefront, Dashboard, SMS, help articles. Bangladeshi merchants often use English words written in Bangla (অর্ডার, ডেলিভারি), so prefer what they actually say over formal Bangla.

**This is a starting list.** Have it reviewed by a native-speaker merchant before the Bangla Dashboard (roadmap phase 33).

| English | Bangla |
|---|---|
| Order | অর্ডার |
| Order number | অর্ডার নম্বর |
| New (order status) | নতুন |
| Confirmed | কনফার্মড |
| Packed | প্যাকড |
| Shipped | পাঠানো হয়েছে |
| Delivered | ডেলিভারি হয়েছে |
| Returned | ফেরত এসেছে |
| Cancelled | বাতিল |
| Cash on delivery (COD) | ক্যাশ অন ডেলিভারি |
| Advance payment | অগ্রিম পেমেন্ট |
| Transaction ID (TrxID) | ট্রানজেকশন আইডি |
| Delivery charge | ডেলিভারি চার্জ |
| Inside Dhaka / Outside Dhaka | ঢাকার ভেতরে / ঢাকার বাইরে |
| Division / District / Thana / Upazila | বিভাগ / জেলা / থানা / উপজেলা |
| Address | ঠিকানা |
| Phone number | ফোন নম্বর |
| Customer | কাস্টমার |
| Product | পণ্য |
| Category | ক্যাটাগরি |

| Place order | অর্ডার করুন |

| Dashboard | ড্যাশবোর্ড |
